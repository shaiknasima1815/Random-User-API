# Random User Generator App

## API Used

Random User API

## API URL

https://randomuser.me/api/

## Description

This project uses the Fetch API to retrieve random user information from the Random User API and display it dynamically on a web page.

## Features

* Fetch data from REST API
* Display user image, name and email
* Loading state
* Error handling

## Technologies Used

* HTML
* CSS
* JavaScript
* Fetch API
